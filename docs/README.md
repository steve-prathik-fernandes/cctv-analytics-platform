## Viewing the diagrams

The `.md` files contain diagrams written in Mermaid. GitHub renders them automatically. In VS Code, install the extension **Markdown Preview Mermaid Support** and open the Markdown preview.

## Viewing the API contract

Open `api/openapi.yaml` in VS Code with the **OpenAPI (Swagger) Editor** extension, or paste it into [editor.swagger.io](https://editor.swagger.io).
